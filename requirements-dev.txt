# 注意: 日常回归测试**不依赖** pytest，且 pytest 在本仓库被刻意配置为
#   **不收集任何用例**（见 pyproject.toml 的 [tool.pytest.ini_options] 及其中说明）。

#   唯一受支持的跑法：
#       python scripts/run_all_tests.py
#   不要用 pytest 跑 tests/ —— 那个 runner 会给日志/trace 改道做隔离，
#   直接 pytest 收集会把测试夹具写进 logs/ 的真实 trace。
