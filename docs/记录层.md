# 记录层（P1）：每一拍她收到什么、想了什么、做了什么

> 目的：让「她为什么这么说」在事后还能查。
> 账本（`data/loop/ledger-YYYY-MM-DD.jsonl`）只记**结论**（act / why / result），
> payloads（`data/loop/payloads/<turn_id>.json`）只记**最后一次****输入**；
> 记录层补中间那段：模型怎么回的、调了哪些工具、工具回了什么、最后说没说。

## 落盘

| 项 | 值 |
|---|---|
| 路径 | `data/loop/trace-YYYY-MM-DD.jsonl` |
| 粒度 | 一行 = 一拍（JSON，UTF-8，无缩进） |
| 体积 | 实测约 8–12 KB/拍；一天 50 拍 ≈ 0.5 MB |
| 上限 | 单文件超过 **64 MB** 就不再写（宁可缺记录，不许写满磁盘） |
| 读取窗口 | 面板与采集器只看**最近两天**的文件；采集器只读文件尾部 768 KB |

写入方：`loop/trace.py` 的 `TurnTrace`，由 `loop/brain.py:run_loop()` 在
「拼完 prompt 之后 / 每次模型调用之后 / 每个工具执行之后 / 收尾」四个点喂数据。
任何异常都被吞掉——记录层坏了不影响她说话。

## 字段

```
turn_id          12 位十六进制，跟账本里的 turn_id 对得上
at / ts          本地时间字符串 / epoch
scene            private | group | mixed（从视界里判断）
db               这一拍读的是哪个 account.db（只存 basename）
dry_run          是否试跑（试跑不会真发消息）
wake             { spontaneous, n_peers, world_stale_s, world_sync_kicked, ... }
trigger_message  主人这句话（如果有）
prompt.system    人设卡 + 四道墙 + 打字规则（截断 16000 字）
prompt.parts[]   [{ name, chars, text }] —— 视界 / 这一拍为什么醒 / 此刻 / 小本本 /
                 这三天的账 / 还没销账的承诺 / 常驻记忆 / 我最近开口 / 怎么表达
prompt.chars     输入总字数
calls[]          [{ i, ms, model, provider, tokens, content, reasoning,
                    tool_calls[{name,arguments}], error }]
steps[]          [{ i, tool, args, ms, obs,
                    receipt{ act, result, ack, target, why, blocked_reason } }]
outcome          { said[{target,ack,text,why}], blocked[], silent, silent_why,
                   n_receipts, ms }
```

截断上限：`system 16000 / part 6000 / content 4000 / reasoning 3000 /
obs 1600 / args 900`（超出时保留头尾并标注截断字数）。

## 三种看法

1. **面板「思」**：最近 24 拍的列表 + 选中那一拍的完整现场（输入各段、system、
   模型调用与 reasoning、工具步、结论）。完整现场只保留最近 6 拍，更早的只剩摘要。
2. **面板「口」**：今天真正发出去的原话（试跑与静默不计）、回执状态、出口管道。
3. **命令行回查**：

```python
from loop import trace
rec = trace.read_turn("adc541e97bf5")
print(rec["calls"][0]["reasoning"])
```

## 与其它两份记录的分工

| 文件 | 记什么 | 谁写 | 保留 |
|---|---|---|---|
| `data/loop/ledger-*.jsonl` | 结论（act/why/result/ack） | `loop/ledger.py` | 长期 |
| `data/loop/payloads/<turn_id>.json` | 最后一次输入原文（system+user） | `loop/brain.py:_dump_payload` | 最近 300 个 |
| `data/loop/trace-*.jsonl` | 全过程（输入 + 调用 + 工具 + 结论） | `loop/trace.py` | 按天，单文件 64MB 封顶 |

## 已知边界

- `calls[].tokens` 是**总数**（供应商返回的 resolved_total），不拆 prompt/completion。
- 工具的 `obs` 是回给模型的那段文字；真正的副作用看 `receipt` 与账本。
- 引擎跑的是启动时的代码：**改 `loop/` 之后要重启引擎**（写 `logs/loop.stop`）才生效。
