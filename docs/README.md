## 二、阅读顺序（第一次读）

0. `外部世界.md` —— 世界从哪儿进来（四类发生、平台事实、旁注、缺口自报）。
1. `账本·事件流.md` —— 先知道世界是怎么被记下来的（唯一真相、只追加、两种视图）。
2. `感知层.md` —— 唯一写入口。
3. `世界窗口.md` + `窗口_渲染规格.md` —— 她这一刻看见什么。
4. `记忆立方体.md` / `自我立方体.md` —— 她还能翻到什么、她此刻是什么状态。
5. `判投记.md` + `判投记_契约.md` —— 唯一有模型的地方：看 → 复述 → 判 → 说/做。
6. `工具包.md` / `出口.md` / `软件适配器.md` —— 手、门、平台差异。

## 三、维护规则（避免再次漂移）

- 讨论期只写 `.test_tmp/decisions_staging.md`，**用户点头后才进正文**，并记 `决定 #N → 文档 §X`，可单条回退。
- 未定项集中放在每份文档的「未定」节，拍板时整条替换成「已定」+ 日期，不留两处。
- 文档里不写「将来会怎样」，只写**现在是什么**；没实现的写进「不做」或「未定」。
- 贴图与文档必须同源：`scripts/3d/render_boards_round2.py` 等生成器里的话术与文档口径一致，改了文档就重画。

> `docs/` 下**不保留任何架构图**：旧的模块流程图会与现在的板子架构冲突，已删除。当前图形事实源只有 `output/3d/viewer_css.html`（点板看正文）。
