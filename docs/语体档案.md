# 语体档案

替「像不像人」这种说不出所以然的事留可回查的原文。**每条必须附她真的发出去过的原话**——没有原文的条目不许进本文件，也不许变成代码判据。

格式：现象 / 原文 / 判据 / 当前取值 / 阈值 / 怎么验证 / 结论。

## #1（2026-10-28）动作写进正文：全角括号旁白

**现象**
- 她会在微信正文里先用一对全角括号写一个动作，再接正话。动作全部是鲸鱼/屏幕意象（鳍耳、尾巴、从屏幕边探头），不是人类身体动作。

**原文**（`data/world.db` → `outbound_receipt`，共 23 条，这里列 12 条；行内 `／` 表示原消息里的空行，即两个气泡）
1. （鳍耳抖了一下）拍到了，我在。
2. 行，那我等你的花生。／（尾巴晃了一下）可别明天醒了忘记。
3. （从屏幕边上探出半个脑袋）花生是给我主人的吧——谢谢P6。
4. （从屏幕边上冒出半个脑袋）主人……我这边好像卡住了。
5. （从屏幕边上冒出头）通了就好，那我这颗心放下了。／你还睡着呢，我不吵——回笼觉睡够了再说。
6. （凑近屏幕看那串引用）唔……我这边只看到一串编号，画的什么我看不见。
7. （尾巴一竖）概率论？我这儿有题。
8. （尾巴一甩）白球那题你还没答我呢。
9. （尾巴尖翘了一下）被夸了。
10. （赶紧把尾巴藏到身后）鱼鳍不能砍——砍了我就浮不上来喘气了。
11. （从屏幕边上探出头）诶，又两张图。
12. （从屏幕边上冒头）答上了，那我那句就收回。

**判据**
- 正则 `[（(][^）)]{2,}[）)]`：出现一对括号且括号内 ≥2 字。纯机械，不依赖词表。

**当前取值**
- 她：23/297 = 7.74%。真人（同一批会话的入站消息）：395/26,606 = 1.48%。人比为 5.2 倍。

**阈值**
- 密度 ≤10%（当前 7.74%，余量 2.3 个百分点）。
- 同一意象不许连续两条重复（例：连着两条都以「（从屏幕边上探出头）」开头 = 刷同一动作）。

**怎么验证**
- 每次改人设卡或开口提示词后跑 `python scripts\voice_eval.py corpus`，看总数（本条要另跑一次性正则统计，脚本见下）。
- 抽查 10 条，确认意象仍不重复、且动作与当句内容相关。

**结论**
- 这是她**稳定的语体特征**，不是毛病：23 条全部是鲸鱼/屏幕意象、且都嵌在与当句内容相关的位置。
- 因此**不改写法**，只守上面两条阈值；若哪天想看是否失控，用「密度 + 连续重复」两个数判断，不用主观感觉。
