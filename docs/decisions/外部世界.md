# 外部世界

> 依据：`output/3d/viewer_css.html` 里最外面那两块板 —— 顶部横板 `addFlat(1300, 620, 2000, 't_outer_flat.png')`（`y = 2000`），与两块竖板 `addBoard(240, 560, 1500, -600, 0, 't_outer.png')`、`addBoard(240, 560, 1500, 0, LLM_Z, 't_outer.png', '外部世界')`；管子：入口管 `addSpine(1000, 1500)`（感知层 `y=1000` → 这里 `y=2000`）、`send() → 平台`（`[1240,0,LLM_Z] → [1380,0,LLM_Z]`）。
>
> 四问先答：**图上是哪块** = 最外框的横板 + 两块竖板（它是**图的外框**，不是图里的一层）；**进来什么** = 没有「进来」—— 它是**发生之源**，事情先在它那里发生；**出去什么** = 我们的动作落到它那里（`send()` 是落点）；**职责** = **不是我们的职责**：它不由我们造、不由我们改、也没有一行代码。

## 1. 图上位置

```
        ┌──────────────── 外部世界（横板 t_outer_flat.png，y=2000）────────────────┐
        │  微信 · QQ · 浏览器/网页 · 文件系统 · 时钟 · 群里的人 · 我们自己的账号      │
        └───────────────┬───────────────────────────────────────┬──────────────────┘
        入口管 addSpine │ (1000,1500)                           │ send() → 平台 落点
                        ▼                                        ▲
                    感知层 ①  ──────────────────────  出口 ◀── 软件 · 适配器
```

- 它画在三块竖板的最右与最上，是**方块的边界**：方块里的东西归我们，方块外的归它；
- 两块竖板（`(1500, -600, 0)` 与 `(1500, 0, LLM_Z)`）不是两个实体，是同一件事的两面：**读的那一面**和**写的那一面**；
- 图上没有一根管子从它直接连到判 / 世界窗口 / 记忆 / 自我 / 工具包 —— 这是全图最硬的一条接线纪律。

| 与谁相连 | 方向 | 说明 |
|---|---|---|
| 感知层 ① | 出（`y=1000` 入口管） | 它产生「发生」，我们只能去看，不能要求它按我们的格式发生 |
| 出口 → 软件 · 适配器 | 进（`send()` 落点） | 我们要说的、要做的，最终必须由**它的**接口执行 |
| 判 / 世界窗口 / 记忆 / 自我 / 工具包 | **不相连** | 它们永远拿不到「外部世界」，只拿得到账本对它的记录 |

## 2. 它是什么（先破一个误解）

**外部世界不是我们要造的一层，是我们之外的一切。**

- 它不是适配器：适配器是**我们造的**、在我们这一侧的翻译器（`软件适配器.md`）；外部世界是**对面那一边**，我们既不能改它的代码，也不能改它的规矩；
- 它不是「世界的模型」：模型（谁在等谁、这条重不重要）在判那里，素材来自账本；
- 它不是一个模块：**没有文件、没有表、没有开关、没有迁移**。代码里不该出现 `external_world` 这样的包名——一旦出现，就说明我们把「环境」当成了「组件」。

一句话：**它是坐标系，不是坐标里的东西。**

## 3. 里面有什么

三样，都不是我们造的：

| 类 | 是谁 | 对我们的意义 |
|---|---|---|
| **外部软件** | 微信 PC 客户端、QQ / NapCat、浏览器与网页、文件系统、邮件 / 日历、系统时钟 | 消息从这儿来，动作往这儿落；它们的接口与脾气决定我们能做到什么 |
| **外部主体** | 群里的人、私聊对象、陌生人、我们的运营者 | 会撒谎、会改口、会撤回、会不告而别；我们只能记录发生，不能纠正他们 |
| **外部事实** | 平台侧状态：撤回、拍一拍、入退群、公告、封号、限流、离线 | 是事实，不是判断；它给了就有，没给就是没有 |

**「我们」也在里面**：机器人账号在外部世界里就是一个普通用户 —— 会被踢、会被限流、会被风控、会因为版本更新而突然做不了某件事。设计上必须承认这一条，否则会写出「平台应该配合我」的代码。

## 4. 我们与它只有两个接触面

| 接触面 | 方向 | 管子 | 由谁承接 |
|---|---|---|---|
| **看**（读） | 它 → 我们 | `addSpine(1000, 1500)` | 感知层 ①：把它的样子翻译成同一种事件；旁注（媒体描述 / 转写）由我们这边的后台处理器读它的字节产出 |
| **动**（写） | 我们 → 它 | `send() → 平台` | 出口（只放行） → 软件 · 适配器（把统一意图翻成它的调用） |

没有第三个接触面。这条纪律的全部意义是：**「外部世界怎么坏了」不许在方块内部被当成一种逻辑分支**——它只能在两个接触面上以「事件 / 失败码」的形式进出。

## 5. 它的性质：五条设计必须假设的事

| # | 性质 | 后果（写代码时必须承认） |
|---|---|---|
| 1 | **不可控** | 登录会掉、接口会变、风控会拦、消息会重复推送、时钟会漂 —— 全是常态，不是异常 |
| 2 | **不可改** | 不许用「理想平台」假设写代码；不许为了好写而伪造事实（伪造一次，账本就永远不可信） |
| 3 | **不完整可见** | 我们只看到它愿意给的：撤回常常拿不到 `newmsgid`、群名单可能滞后、附件可能下不下来 |
| 4 | **有延迟、会乱序** | 同一秒多条、重连补发、跨天到达；排序靠我们自己的 `sequence`，不靠它的时间 |
| 5 | **有第三方意志** | 人会撒谎与改口；平台的规则会为了它自己而变 —— 这些都不是 bug，是环境 |

## 6. 谁替我们对付它

| 活 | 归谁 | 一句话 |
|---|---|---|
| 把它变成同一种形状（事件化 / 身份证 / 去重 / 失败留痕） | 感知层 ① | 我们唯一的读入口 |
| 把它的事实原样上屏 | 世界窗口 | 只渲染账本后缀，不联网、不现查 |
| 把「能发什么、需要什么权限」问清楚 | 软件 · 适配器 | `capabilities()` 在**我们这一侧**，不是它给的 |
| 把统一意图翻成它的调用 | 软件 · 适配器 | 一次投递 = 一次平台调用；失败不重发 |
| 决定说不说、说什么 | 判 | 且判**看不到它**，只看到账本对它的记录（世界面） |

**为什么判不能直连它**：直连就等于「模型现场联网看群」，同一份账本两次跑出不同判断，留痕与重放全废（`判投记.md` 判板无状态的前提）。

## 7. 为什么它值得单独写一篇

因为它是**所有「不可能」的来源**，也是所有甩锅的终点：

- 「她怎么没反应」→ 可能它在限流（接触面 1 的读数），可能我们没读到（感知层失败留痕）；
- 「她怎么说了这个」→ 判只看到账本，账本只记它给过什么；
- 「为什么不能做得更好」→ 有些事它根本不让我们做（能力声明里写着做不到）。

它的名字只有一个用途：**说清「谁的责任」**。凡是在它那一侧的，我们不承诺；凡是在方块这一侧的，不许拿它当借口。

## 8. 边界（它不管什么，也不该被当成什么）

| 不许 | 为什么 |
|---|---|
| 把它写成模块 / 表 / 开关 / 迁移 | 它不是我们造的；写出来就是把环境当组件 |
| 在它那里做事件化、去重、判断、补全 | 它是发生之源，不会替我们整理 |
| 让判 / 世界窗口 / 记忆 / 自我 / 工具包直连它 | 会破坏可重放与「三面只读」 |
| 用它的接口形状去定义我们的字段 | 字段是我们的契约，平台差异只活在适配器里 |
| 把「平台不给」解释成「没有发生」 | 那是两种失败：**没拿到**（适配器 / 感知层的账）与 **没有发生**（事实） |

## 9. 量具

它自己没有量具（它不是我们的代码）。能测的全在两个接触面上：

| 读数 | 口径 | 归属 |
|---|---|---|
| 读到多少 / 漏了多少 | 它声明发生了多少 vs 实际入账多少（差额必须有原因码） | 感知层 ① |
| 原样保真 | 抽 N 条，账本原文与平台侧逐字节一致 | 感知层 ① |
| 发出去成没成 | 每条的 `Receipt`（`sent` / `sent_unconfirmed` / `failed`） | 出口 |
| 做不到的原因分布 | 六类错误码（`auth_expired` / `rate_limited` / …） | 软件 · 适配器 |
| 它变了没有 | `capabilities()` 变化次数 | 软件 · 适配器 |

## 10. 不做

- 不建「外部世界」模块 / 表 / 开关（它不在我们的代码里）；
- 不假设平台会配合我们（版本、限流、接口稳定性都不承诺）；
- 不在方块这一侧为平台的坏行为加特例分支（只加错误码与留痕）；
- 不让任何读面直连它（三面只读，读的永远是账本）；
- 不把它的沉默当事实（没拿到 ≠ 没发生）。
