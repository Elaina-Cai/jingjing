# 情绪层：存储与读取

> **状态（2026-10-20）：本文档记的是 v0.5 数值模型的推导过程**（`valence` / `arousal` / `trust`、基线、半衰期、±0.20 限幅、日上限 3 条）。该数值模型已在 `自我立方体.md` v0.6 撤销，现行口径是「事件清单 + 轻/中/重档位 + 时间窗」与「可核对事实」。**本文只作推导留痕，不作实现依据**；其中「证据行只追加、折叠行、读时派生」这套存储机制仍然有效。

## 0. 一句话

情绪是**会话级**的派生状态：证据只增不改地记「哪里让她起了什么反应」，当前值按会话折叠成一行，读的时候才按半衰期衰减。

## 1. 本文边界

只讲两件事：**存在哪、怎么取**。

- 观察器（哪四路在看、看什么、怎么给权重）→ `docs/decisions/穷举整改_情绪层_P1设计.md`，本文不重复。
- 语气档怎么取、prompt 怎么拼 → 不在本文。
- 与态度层共享的存储约定（证据只增不改 / 无行=unknown / 缓存可关 / 能重算）→ 见 `docs/decisions/态度层_存储与读取.md` §3–§8。

[6] 为什么不是「放内存」

    - 重启会失忆：「她刚才还在气」必须在 20 秒重启后仍然成立
    - 两个进程各算各的：启动器与调度器会「这边在气、那边没事」
    - 审计要能回答「为什么此刻 -0.17」→ 指到某句话（basis 的 span）
    - 换 k / 换观察器要能用历史事件重算 ⇒ 事件必须是持久真相
    内存里只留缓存：TTL ~60s，写入即失效，关掉也必须算对。

[7] 一致性：每一行都能由证据重算（对不上就是 bug）
