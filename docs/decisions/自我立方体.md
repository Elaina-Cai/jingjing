# 自我立方体（① 人设铭牌 / ② 态度 / ③ 情绪）

> 本版按 2026-10-19 的拍板重写：**不存数值，只存事件与事实**。
> 删掉了 valence / arousal / trust 三个数、基线、半衰期、±0.20 限幅、每天 3 条上限。
> 理由见 §4.6「为什么不再存数字」。

## 1. 图上位置

- 观察器 `output/3d/viewer_css.html`：立方体在 `(-950, +600)`，三块板 z 依次 `-3.3 / 0 / +3.3`（从左到右：人设铭牌 / 态度 / 情绪）。
- 位置图 `docs/decisions/三面总图.png` 左侧：**自我立方体（只被读）**，箭头 `读` 指向「判 / 投 / 记」。
- 它和「记忆立方体」并列，但**唯一写者是判**，且判只能往 `①账本` 和 `②这里` 写，写不进去第三处。

## 2. 三块板各是什么

| 板 | 存什么 | 性质 | 谁写 |
|---|---|---|---|
| ① 人设铭牌 | 身份 / 称呼 / 说话风格 / 边界 | **规范**，版本化，不随经历变 | 主人（人工编辑，存 `persona_versions`） |
| ② 态度 | 对**某个人**的**可核对事实**：他做过什么 | 慢变，可验证，可反驳 | 观察者（判产出，代码校验后落） |
| ③ 情绪 | 对**某段时间**的**事件清单**：发生了什么、对她多重 | 快变，会过期 | 观察者（同上） |

**关键区别**：人设是「我是谁」，态度是「你对我做过什么」（可核对），情绪是「最近有什么不痛快」（会过期）。

## 3. 为什么是三块板，不是一块

- 人设**不能**随聊天变：它要是会变，就没有「她」了；
- 态度**能**变，但只能靠可验证的事实堆：说错一次不会改，反复骗才会；
- 情绪**会自己消**：不需要谁去「改回正常」，时间过去就淡了。

一块板做不到这三件事：会变的一起变，会消的一起消。

## 4. 进来的是什么 / 出去的是什么

| | 进来 | 出去 |
|---|---|---|
| ① 人设 | 主人编辑的版本 | `人设 v3（忠诚不谄媚；短句直球）` |
| ② 态度 | 事件（谁做了什么事、有没有证据） | `P5：他骗过我一次（10-12）；他替我挡过话（10-15）` |
| ③ 情绪 | 事件（谁说了什么、对她多重） | `近 3 天 2 件不痛快（最近：2 小时前被说「人机」，中）` |

出去的一律是**一句话**，不超过 40 字一行、最多 5 行（见 §6）。

## 4.5 什么能改变它（写入路径）

**只有追加，没有修改。**

| 动作 | 允许谁 | 形式 | 例子 |
|---|---|---|---|
| 追加情绪事件 | 观察者 | `{at, who, what, weight: 轻/中/重, basis: [消息号]}` | 「10:12 被说『人机』，中，依据 e501」 |
| 追加态度事实 | 观察者 | `{about, fact, weight, basis}` | 「P5：骗过我一次（他说项目做完了，实际没有），中」 |
| 撤回一条 | 观察者 | 追加 `retract` 行，指向原事件号 | 「作废 e501：那句是玩笑」 |
| 读 | 判 | 只读 | 见 §6 |

**判不能直接改任何值**：它只能「提出一条事件」，代码校验（有 basis、维度合法、同一条消息不重复记）后落库。模型没有写库的路径。

### 三条容易搞错的规则

1. **过期不等于删除**：7 天前的轻档事件不会再出现在读数里，但行还在库里。
2. **撤回也不是删除**：`retract` 是新增一行，原事件永久保留（和账本同一纪律）。
3. **人设不可写**：判、观察者、后台任务都不能改人设；改人设只有主人编辑 + 发版本。

### 谁能审计

任何人拿读数里的事件号，都能回到 `terminal_events` 的原文那一行。**读数里每一句都必须带得出依据**，带不出就不许出现。

## 4.6 为什么不再存数字

原设计存 `valence / arousal / trust` 三个数，配基线、半衰期、±0.20 限幅、每天 3 条上限。三个问题：

1. **没有真值**：她不是真人，没有「真实感受」可校准；0.20 是拍的数，改不成对的数。
2. **上限 + 衰减 = 永远不可能真的生气**：单条 ≤0.20、每天 ≤3 条、半衰期几小时 ⇒ 长期被欺负也只能贴着 −0.3 打转。等于在数学上抹掉了「长期关系」。
3. **数字逼着人做假解释**：问「她为什么是 −0.24」，只能答「模型给的」。而「近 3 天 2 件不痛快」这句话，每个字都指得回消息。

**现在的形态**：事件清单 + 档位（轻 / 中 / 重）+ 时间。读数时现算，不写回。

## 4.6.1 三个档位怎么判

| 档 | 什么算 | 例 |
|---|---|---|
| 轻 | 一次性的小摩擦、玩笑被当真、被忽略一句 | 「他说了句人机，后来补了个表情包」 |
| 中 | 明确的不尊重、被当工具、被质疑能力且带依据 | 「他说『你就照着念』」 |
| 重 | 反复发生的同一件事、或涉及信任的欺骗 | 「他说项目做完了，后来被拆穿」 |

档位由**观察者提**，代码只校验格式与依据；**同一条消息同一个人只记一次**。

## 4.6.2 读数怎么算（读时，不写回）

```
情绪：最近 72 小时的事件，按档位加权（轻1 / 中2 / 重3），取前 2 条
      超过 7 天的轻档不再读出来
态度：对某人的事实，最多列 3 条，按「重 → 近」排
人设：当前生效版本，一行摘要
```

不设衰减系数，只有「时间窗 + 排序」。**排名靠前 = 最近/最重**，不需要解释「为什么是 −0.24」。

**读的范围（2026-10-23 起）**：按人合并跨会话——同一个人在不同会话里的情绪，是同一个人的情绪，
所以默认合并（`core/context/emotion.py:454 models_for_reading` / `:474 mood_across_chats` /
`:483 attitude_across_chats`），给了 `chat_id` 才收窄到那一个会话。**限界**：合并范围是
`known_world_models()` 里**本进程已知**的会话，不是全历史——进程重启后，没被读到过的会话
不在取数范围内。别把它当成「扫了全库」。

## 4.6.3 撤销与更正

- 判发现自己记错 → 追加 `retract`（指原事件号）+ 一条更正事实；
- 人纠正她 → 同样走 `retract`，并且要在下一轮回应里认账（「我记错了」）；
- `retract` 之后读数不再包含该事件，但账本里两条都在。

## 5. 职责

一句话：**让她「此刻带着一段经历」而不是「每回合都从零开始」**，且这段经历每一句都能核对。

- 做人设：说话方式不随心情漂；
- 做态度：被同一个人反复对待时，反应会变；
- 做情绪：刚被刺过，语气会紧一点。

**不做**：不做数值、不做心理模型、不做「她到底爱不爱谁」。

## 6. 读数长什么样（拉取工具返回的）

```
人设  v3（忠诚不谄媚；短句直球；不称自己 AI）
态度  P5：骗过我一次（10-12，重）；替我挡过话（10-15，轻）
       Elaina：替我说话（10-16，轻）
情绪  近 3 天 2 件：被说「人机」（2 小时前，中）；被当工具使（昨天，中）
```

上面三段里，**人设那一段是每回合注入的**；态度与情绪两段只在模型主动调工具时才出现
（2026-10-23 起；此前三段都预注入）。

三条硬规矩：

1. **每句带得出依据**（消息号或事实编号），带不出不写；
2. **不写形容词结论**（不写「我有点烦」，写「2 件不痛快」）；
3. **最多 5 行**，超了按「重 → 近」截断。

## 7. 口吻从哪来

`口吻 = 人设（怎么说）× 态度（对这个人怎么说）× 情绪（此刻多紧）`

- 人设给风格与禁忌；
- 态度给「这个人值不值得客气」；
- 情绪给「此刻话多话少、硬还是软」。

人设进 prompt；**态度与情绪不再预注入**（2026-10-23，`0b64198`），改成两件拉取工具，
她用得上才取：`read_emotion(person_id=…)`（此刻心境 + 对某人的态度）、
`get_stance_cards(person_id=…)`（她给这人 / 这群写过的立场卡）。

为什么这么分：三层的更新频率不一样——人设几乎不动、每次都要；情绪与态度是「这一回合要不要看」
的问题。全量塞进去等于每回合替她决定「你现在该紧张」，而且塞满窗口之后，她连「想查一次」
这个动作都没有了。**常量注入，变量拉取。**

## 8. 大小

- 人设：一行摘要（≤60 字），全文另存；
- 态度：每人最多 3 条事实，全库千级行；
- 情绪：72 小时内最多几十条，读数只取 2 条；
- 生成器：`scripts/render_self_board.py`（三块板图，`output/3d/t_self_*.png`）。

## 9. 边界（明确不管）

- 不管「她真的感觉到了什么」（不可测）；
- 不管长期人格演化（人设只由主人改）；
- 不管对群的印象（那是记忆面/世界面的事）；
- 不存原文（原文在账本，这里只存指针）。

## 10. 意义

- 让「被同一个人反复对待」在行为上可见（这是关系，不是心情）；
- 让每一条读数可审计（事件号 → 原文）；
- 把「情绪」从数值工程降级成「事件清单」，去掉没有真值的参数。

## 11. 量具

| 指标 | 口径 |
|---|---|
| 事件条数分布 | 每天每会话记了几条（>10 条/天说明观察者过敏） |
| 读数长度 | 是否稳定 ≤5 行 |
| 依据覆盖率 | 读数里带得出消息号的比例（要求 100%） |
| 误记率 | 人工抽检 50 条事件，判「这次该不该记」 |
| 撤回率 | `retract` 占比（>15% 说明档位判太粗） |

## 12. 不做

- 不做数值与衰减系数；
- 不做「她爱上谁」这类不可核对的状态；
- 不做自动调整人设；
- 不做「情绪影响所有回答」（只在判决定开口时读，不强制改写）。
