## 2. 优先级（27 条，三合一：该抄什么 / 为什么 / 先抄哪个）

> 判断口径：① 对着鲸鲸真实踩过的坑（原子写/截断/假失败/按行号改错位）；② 能在 Python 侧照搬，不引入 Node 依赖；③ 改一处就见效。
> 每条三段：**做什么** → `原文`（surfcore 里的出处）→ **为什么**（对应我们哪个具体毛病）。


> 状态的四种取值：**已完成**（说明做了什么 / 落在哪个文件 / 何时验证过）、**未开工**（说明缺口在哪、动手前要先摸清什么）、**不适用**（说明为什么这条在这个仓里不成立）、**部分完成**（剩下的那半句必须写清楚）。没有状态行 = 还没人看过这条。
