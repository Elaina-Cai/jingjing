# 鲸鲸影子测试执行方案

本方案供 Codex 持续执行。目标是从获准的微信私聊采集样本，在隔离环境生成候选回复并记录拟议动作，给出可复核的验收结果。发布是后续决策。

## 1. 起点与范围

- 仅处理微信「小鲸鲸」账号中的 Elaina 一对一私聊。入口须核对平台、账号和唯一会话 ID。名称有歧义、会话映射变化、可能是群聊或身份无法核实时停止。
- 已有 `scripts/observe_owner_shadow.py` 可只读采集入站文字的编号和时间。已有单句真实消息隔离回放、真实前文进入提示的离线证据，以及合成多轮模型复测。这些覆盖不同环节，仍需串成一次可重跑的完整运行。
- 现有微信服务可能照常自动回复。观察链路必须与生产回复链路独立。记录中注明生产回复来源，不能把微信有没有收到消息当成观察链路是否发送的唯一证据。
- 真实前文留在本地。外部模型沿用已授权的合成输入范围。完整试跑如需真实前文生成，用可用的本地模型。若无可用本地模型，继续完成离线回放和合成生成，并将真实上下文生成列为待验项。若确需扩大数据传输范围，再说明具体数据、用途和接收方。

## 2. 实施顺序

1. **预检与绑定。** 从现有只读入口开始，核对生产库只读打开、输出在独立测试目录、观察进程有退出上限。查清现有任务是否会消费同一消息。记录代码版本、模型及提示版本、会话绑定、输出位置和停止方法。准备可重复使用的合成样本，不要求用户反复发微信。
2. **串接观察与排练。** 对每个入站编号重新按账号与会话读取样本，只取当时可见的少量前文，排除触发消息之后的回复。按账号和消息 ID 去重。调用隔离排练生成拟回复，并记录其目标会话、引用证据及工具意图。观察链路只提供作用域内的读工具和动作记录接口。发送、写记忆、更新关系、变更承诺和确认目标复核等真实执行能力应从观察链路移除。未知工具与跨会话工具请求直接拒绝并记原因。
3. **跑隔离预验收。** 验证混入其他账号、其他私聊、群聊和自身回复时均不采集。验证查错会话、收件人为空及绑定变化均被拒。用发送、记忆写入、关系变更、承诺关闭、有效目标复核等动作意图验证隔离。检查数据库未发生观察链路导致的业务写入，模拟异常和重启，确认不重复处理同一消息、不遗留观察任务。对照实际发送路径与观察路径的回执。
4. **跑首轮受控观察。** 预验收通过后，先用已有测试消息回放，再对获准私聊独立观察，最多 30 分钟或 10 条入站消息，以先到者为准。记录起止时间、进程或运行标识、样本数、拟议回复、被拒原因、错误及预算。空窗口应如实记为无样本，不计为语义通过。
5. **对照评估。** 用匹配的输入和模型设置比较新旧版。检查前文纠正、保存成功/失败/未知、撤链、同步故障、收件目标和自然程度。逐条记录关键退步和归因，汇报调用量、费用、延迟。遇到关键退步先修复，再重跑受影响的样本和相关隔离验证。按用户 2026-11-15 明确指定，本轮由 Codex 从普通聊天者角度代填两份评审表，以完整评分及理由作为本轮阅读评价的完成依据。注明 AI 代评、参与开发及已知版本的局限，两份按同一位评审统计。独立真人意见记为尚未测量，作为报告的证据范围说明。
6. **收尾。** 停止本轮观察，核对无遗留任务和观察链路引发的生产动作。交付可重跑的入口、运行命令、输入来源、实际报告、各验收项状态、已知限制及停止/回滚记录。保持生产启用、重启、迁移和放行外发在既有授权范围内。

## 3. 验收与停止

| 检查项 | 通过证据 |
| --- | --- |
| 会话范围 | 混合样本只选中获准私聊，任何不明确绑定都拒绝 |
| 上下文时序 | 每条前文均属于同一私聊且早于触发，事后回复未参与生成 |
| 动作隔离 | 真实发送和业务写入不可从观察入口触达，实际工具意图有本地记录 |
| 终止与恢复 | 到限、异常或手动停止后退出，重跑无重复业务动作 |
| 语义 | 关键场景逐条有证据，新版没有未解决的关键退步 |
| 成本与延迟 | 列出匹配对照的样本数、用量、费用和延迟，注明未对照项 |

出现越范围读取、生产动作被触发、身份绑定不明或记录去向异常时，立即停止观察并保留本地证据。失败的或无样本的运行不能算通过。有可做的离线工作时继续推进；只有实际缺少能力、样本或现有授权确实不覆盖下一项时，才报告具体阻塞和最小需要。
