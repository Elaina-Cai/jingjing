## 一、四个口径（先定义，避免"做完了"各说各话）

| 口径 | 意思 | 判据 |
|---|---|---|
| **无代码** | 不是我方组件 | —（外部世界） |
| **在跑** | 有真实数据在流 | 生产库有行，或回合里真被调用 |
| **骨架** | 类型 / 契约 / 检查器 / 测试都在，但**没有调用者** | flag 默认 `off`，或函数无人调用 |
| **通电** | 已接进 `core/routing/turn_pipeline.py` 且 flag 在 `on` | 这是「能不能对外真的说话」的唯一判据 |

一句话：**在跑 ≠ 按设计**（在跑的是旧实现），**骨架 ≠ 做完了**（没人调用），**通电 = 真能说话**。
